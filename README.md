# Cthulhu Dreamt — Foundry VTT System

Version 0.1.0 — Foundry VTT v14 compatible.

## Installation

1. In Foundry VTT, go to **Game Systems** → **Install System**
2. Paste the manifest URL or place this folder in `<foundry-data>/systems/cthulhu-dreamt/`
3. Launch a new World using the **Cthulhu Dreamt** system

## Features (v0.1)

- Full character sheet with left-side tab navigation (Stats / Inventory / Goals)
- 6 Attributes (Strong, Agile, Cunning, Vigilant, Careful, Tenacious) with pip-click spending
- Physical & Mental Stress bars with wound tracking
- Inventory system: Tools, Armor, Weapons, Gear with load calculation
- Goals & IP tracking
- Standard d12 rolls with TN dialog and AP spending
- Dark Blue / Ice Green aesthetic matching the Cthulhu Dreamt brand
